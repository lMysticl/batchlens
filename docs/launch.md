# Launch material

These are drafts for the maintainer to post after reviewing the release.

## One-sentence introduction

BatchLens puts a React operations console inside your Spring Batch application: inspect a failed step, see committed work, and restart from the checkpoint.

## A useful demo

Start the invoice import, let invoice 137 fail, inspect the error and chunk counts, then restart and show all 300 unique invoices.
Show the actual application, the limitation that matters, the quick-start command,
and the release link. Use the real screenshots in `docs/assets/`.
